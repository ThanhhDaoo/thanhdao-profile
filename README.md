## 🌟 Giới thiệu tổng quan

Hồ sơ năng lực tổng thể (**Full-Cycle Perspective**), kết hợp tư duy phân tích nghiệp vụ bài bản (**IT Business Analyst**) với năng lực phát triển phần mềm đa nền tảng:
- **Backend Architecture:** Java Spring Boot, C# ASP.NET Core, Python AI, Redis, MySQL, SQL Server, Docker.
- **Mobile & Frontend Development:** Flutter & Dart (BLoC / GetX / Provider), Swift iOS Native *(Đang nghiên cứu & học tập)*, React, Next.js, Modern Tailwind CSS.
- **IT Business Analysis & Modeling:** UML, PlantUML, ERD, SRS, Use Case Matrix, Power BI, Quy trình phân tích yêu cầu phần mềm chuẩn Agile/Scrum.
